# FWriter

Терминальный (TUI) редактор глав [фикбука](https://ficbook.net) с локальной историей версий — для авторов и их помощников: соавторов, переводчиков, бет и гамм.

> [!WARNING]
> Ранняя разработка. Текст пока правится только в сырой разметке фикбука: режим «как у читателя» и автозамена при вводе ещё в работе.

> [!NOTE]
> Это неофициальный клиент, он никак не связан с фикбуком. Программа читает страницы сайта, поэтому может перестать работать после очередного обновления фикбука.

## Возможности

Уже работает:

- вход по кукисам браузера; данные входа хранятся в системном хранилище паролей;
- список ваших фанфиков и глав, сгруппированный по ролям: автор, соавтор или сопереводчик, бета, гамма;
- правка названия и текста главы прямо в терминале, в родной разметке фикбука; теги ставятся горячими клавишами;
- автосохранение черновика и локальная история версий;
- дифф между любыми версиями, включая ревизии с сайта, и восстановление версии;
- синхронизация с сайтом: черновик обновляется до новой ревизии, при необходимости с трёхсторонним слиянием и его ревью;
- отправка правок на сайт и создание новых глав;
- смена статуса главы: опубликовать, скрыть в черновики, отменить отложенную публикацию;
- твики: оформление абзацев, типографика, починка тегов;
- работа без сети.

В планах:

- правка в виде «как у читателя», без тегов, с переключением на разметку;
- автозамена при вводе (кавычки, тире и т. п.) и настройки к ней.

## Как устроена синхронизация

Главная копия главы - на сайте, у вас - черновик от последней скачанной ревизии. Все ревизии с сайта сохраняются локально. Если кто-то (бета, соавтор) поправил главу на сайте, черновик обновляется до новой ревизии; если правки пересеклись с вашими, открывается экран слияния, где для каждого спорного места выбирается ваш вариант, вариант сайта или оба. Отправить на сайт можно только черновик, обновлённый до свежей ревизии.

Новая глава сначала существует только у вас и при первой отправке создаётся на сайте как черновик. Уже опубликованные главы при отправке сохраняют свой статус.

## Установка

Нужен [uv](https://docs.astral.sh/uv/getting-started/installation/). Подходящий Python (3.14) uv скачает сам.

```sh
uv tool install git+https://github.com/Razhon/FWriter
```

Запуск:

```sh
fwriter
```

Обновление: `uv tool upgrade fwriter`.

## Вход

Логин и пароль программа не спрашивает: она входит под сессией из вашего браузера. Для этого нужны кукисы и User-Agent.

1. Войдите на ficbook.net в браузере.
2. **Кукисы.** Поставьте расширение (например, [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)), откройте его на вкладке с фикбуком и скопируйте куки в формате JSON.
3. **User-Agent.** Нажмите `F12`, откройте вкладку **Network** и обновите страницу. Выберите любой запрос к ficbook.net и скопируйте значение `User-Agent` из раздела **Request Headers**.
4. Запустите `fwriter`, вставьте кукисы и User-Agent в поля и нажмите «Войти».

При следующих запусках программа войдёт сама. Если сессия на сайте закончится, она снова попросит данные.

> [!CAUTION]
> Кукисы дают полный доступ к вашему аккаунту на фикбуке. Никому их не передавайте. FWriter хранит их только у вас на компьютере, в системном хранилище паролей (через [keyring](https://pypi.org/project/keyring/)), и отправляет только на ficbook.net.

## Управление

Клавиши текущего экрана видны внизу, в строке подсказок.

| Действие | Клавиша |
|---|---|
| Стартовая вкладка со списком глав | `F1` |
| Переименовать главу | `F2` |
| Дифф и история версий (там же `S` - сохранить версию, `R` - восстановить) | `F3` |
| Ревью последнего слияния | `F4` |
| Отправить на сайт (нажать дважды) | `F5` |
| Статус главы | `F6` |
| Справка по оформлению | `F8` |
| Твики | `F9` |
| Теги: `<b>`, `<i>`, `<s>`, `<center>`, `<right>`, `<footnote>`, `<tab>` | `Ctrl+B`, `Alt+I`, `Ctrl+T`, `Ctrl+E`, `Ctrl+R`, `Ctrl+N`, `Tab` |
| Закрыть вкладку главы | правый клик по вкладке |
| Удалить в корзину главу, которая есть только у вас (нажать дважды) | `x` на стартовой вкладке (или крестик мышью) |

Без сети программа открывает главы из локальных черновиков; вернуться в онлайн можно кнопкой «Повторить вход» на стартовой вкладке.

## Разработка

```sh
git clone https://github.com/Razhon/FWriter
cd FWriter
uv sync
uv run fwriter
```

Проверки перед коммитом:

```sh
uv run ruff check src tests
uv run ruff format --check src tests
uv run pyright src tests
uv run pytest -q
```
